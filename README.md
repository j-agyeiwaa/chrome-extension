## How to Install & Use

Since this extension is hosted on GitHub, you can easily load it into Google Chrome (or any Chromium-based browser like Brave or Edge) in Developer Mode:

### Step 1: Download the Code
* **Option A (Download ZIP):** Click the green **<> Code** button at the top of this repository, select **Download ZIP**, and extract the folder to your computer.
* **Option B (Clone via Terminal):**
  ```bash
  git clone https://github.com
  ```

### Step 2: Load the Extension in Chrome
1. Open Google Chrome and go to `chrome://extensions/` in the address bar.
2. Turn on **Developer mode** using the toggle switch in the top-right corner.
3. Click the **Load unpacked** button in the top-left corner.
4. Select the extracted project folder containing the `manifest.json` file.

### Step 3: Run the Extension
1. Click the **Extensions** icon (puzzle piece) in the top-right toolbar of Chrome.
2. Pin the extension for easy access and click its icon to start using it.
